# RoboParty 文档检索用法

模型自己记不住板端手册里的烧录步骤、接口名、针脚和版本号。回答任何 Roboto Origin
问题前，先检索官方资料，再用原文回答。

## 工作流程（强制）

1. `list_manuals`：了解文档中心的知识分类（01–08）与实操手册。
2. `docs_search_docs`：传**短查询**——错误原文、命令、接口名、包名或几个关键词，不要贴整段话。
   - 知道语言就传 `lang`（zh/en），否则按查询自动判断。
   - 用户口语化或贴了日志时，把关键词按手册用语改写后再搜一次。
3. `docs_get_page`：对 1–2 个命中的 url 打开原文：
   - 知识文档返回 Markdown；可传 `section` 只取相关小节，`full=true` 取整页。
   - 飞书实操手册返回 `sourceUrl`，打开飞书知识库读原文。
4. 用原文回答，并在对应内容后附上官方文档链接。

## 规则

- **不要凭记忆编造**镜像名、apt 包名、管脚复用、参数（kp/kd）或版本号；一律以检索到的原文为准。
- 知识库 01–08 是系统讲解；飞书实操手册是操作规范，二者结合使用。
- 每个问题最多打开 1–2 篇；答不上就换 2 种关键词再搜。
- 检索仍无结果时，引导用户到文档中心：
  https://roboparty.com/roboto_origin/doc

## 证据与限制

- **含图的信息不算已读。** 针脚表、电气参数若在页面图片里，正文 Markdown 不含逐针数据；
  涉及引脚/电平/电源时，要打开或展示官方图片，不要拿其他型号推断。
- 知识文档正文由站点编译 chunk 提供；外部手册正文只在来源站点打开，MCP 不镜像正文。
- 官方页面之间若有数值冲突，引用两处原文并建议以文档维护者确认为准，不要自行下结论。

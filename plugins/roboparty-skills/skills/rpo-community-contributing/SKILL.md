# 社区规范与贡献指南

> 权威来源（先读原文，再动手）：[社区规范与贡献指南](https://roboparty.feishu.cn/wiki/YVnYwOgSPiHFAKkzZqHcmSCTnQe)

## When to use

当用户的问题涉及「社区规范,贡献指南,怎么贡献,发帖规范,community,contributing」时使用本技能。

## Instructions

1. 按《社区规范与贡献指南》参与社区、提交内容。
2. 对外发布引用公开链接。
3. 贡献代码/文档前确认许可证要求。

## 使用约定

- 涉及版本号、镜像名、针脚、包名、API、参数时，先用 roboparty-docs MCP 的 `docs_search_docs` / `docs_get_page` 核对官方原文，**不要凭记忆编造**。
- 用原文内容回答，并附上上方权威来源链接。
- 每个问题最多打开 1–2 篇文档。

## Safety

- 接线、烧录、上电类操作：先断电/确认急停，核对电压与接口，必要时让用户确认后再执行。
- 只读排查优先；任何可能改变设备状态的动作，执行前说明影响。

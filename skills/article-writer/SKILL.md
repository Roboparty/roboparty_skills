# 技术文章写作

把工作沉淀成可发布的中文技术文章。事实与参数来自官方文档或用户提供的素材，不虚构。

## 流程

1. 明确主题、目标读者（开发者 / 高校师生 / 爱好者）与要解决的问题。
2. 用 roboparty-docs MCP 核对其中的命令、版本、接口、参数，附来源链接。
3. 组织结构：背景与问题 → 环境/准备 → 步骤（含可复现命令）→ 结果 → 常见问题 → 参考资料。
4. 先产出 Markdown；命令用代码块，关键步骤配截图或示意图（图片用 `![图注](url)`）。
5. 渲染成单文件 HTML（内联 CSS，无外部依赖），用浏览器打开预览，确认排版与图片。

## 约定

- 命令、包名、版本、针脚必须可核对，无法确认的标注「以官方文档为准」。
- 不夸大、不写未经证实的对比结论；对外发布前提醒用户核对事实与许可证。
- 配图版权需合规；没有图片时用文字或简单示意图，不盗用他人素材。
